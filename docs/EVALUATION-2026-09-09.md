本次按以下顺序修改工作区源码，未修改业务数据库、历史评测数据或已冻结的 candidate/candidate-v2：

1. **证据隔离**：文件去重必须匹配项目、内容、类型、来源、敏感度和实例上下文，并验证落盘哈希；持久化原始文件名，Artifact ID 回放也能找回 basename。

4. **执行期限**：题组全局截止时间约束阶段、Planner 重试、Worker 和验证回放；收尾 fallback 仅使用剩余时间，断连时不再额外调用模型。流式进程硬超时直接结束，不再追加 grace，也不会因无换行输出阻塞计时。平台提交仍使用平台适配器的有限网络超时，避免丢弃已获得的有效候选。
